# 数学课堂资源台

一款给初 / 高中数学老师用的上课资源软件。按教材章节组织课件、习题、试卷，一键打开；内置黑板（手写板）、资源拖拽整理。离线优先，数据存在你自己的电脑上。

## 下载与安装

1. 打开本仓库的 **Releases（发布）** 页面：<https://github.com/zhzzzzz1/mathclass-app/releases>
2. 下载最新版的 `数学课堂资源台-v1.0.zip`
3. 把压缩包解压到任意文件夹（例如桌面）
4. 双击其中的 `数学课堂资源台.exe` 即可使用

> 首次打开时，Windows 可能弹出“Windows 已保护你的电脑”（SmartScreen 拦截，因为软件未购买代码签名证书）。这是正常现象，点击「仍要运行」即可。

## 功能简介

- **教材目录**：初中（浙教版）、高中（人教 A 版，对应浙江新高考）按章节浏览
- **资源卡片**：PPT / PDF / Word / 视频等一键打开；可拖拽排序、按章节添加资源
- **黑板**：画笔 / 板擦 / 直线 / 矩形 / 圆，多色可选，撤销重做、多页，可导出图片
- **离线优先**：资源文件在你本机，软件只记录路径；用「导出 / 导入」可备份与迁移
